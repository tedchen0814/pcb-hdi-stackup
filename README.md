# PCB 互動動畫教學

版本 v1.3，更新 2026-10-07。各章節介面、解說、工程補充與問答採繁體中文／英文並列。

## 開啟方式

以 Edge 或 Chrome 開啟 `index.html`，即可離線使用；沒有套件安裝、帳號登入或付費 API 需求。原始疊構圖已內嵌於網頁。若要使用頁面中的修訂稿連結，請讓 `review.md` 與網頁位於同一資料夾。

## 教學操作

- 入門說明與工程觀察合併顯示：右側解說先用白話說明，下方「工程觀察」補充圖面數據、待確認事項與廠內用語。
- 結構探索：選取銅層、Core、PP 或防焊；可展開剖面及依圖面厚度比例顯示。下方原圖會用綠框標出選取的列，也可以直接點原圖的列來選層。
- 材料介紹：四個不同畫面分別為「拆解 PP 成分／Prepreg constituents」、「壓合與樹脂填隙／Pressing and resin flow」、「固化與層間結合／Cure and layer bonding」、「Core 與 PP 對照／Core vs. prepreg」。填隙階段保留壓板、流動箭頭與參與壓合的銅箔；固化後移開壓板、停止流動，展示結合後的層疊。最後一張為材料角色對照，不是 PP 固化後變成 Core 的下一步。
- 製程播放：中央兩層、四次對稱積層及後段加工，共 38 步。可播放、暫停、前後逐步、重播、拖曳時間軸或直接跳至某次積層。
- 孔連接：比較單一微盲孔、堆疊微孔、錯位微孔、全厚度通孔，以及「自選路徑」：選起點與終點層，顯示需要幾段相鄰層連接、是否經過中央孔。播放只顯示當前孔型的導通路徑，完成後停止。
- 製程播放下方有計數器（銅層數、壓合次數、已填孔微孔層、累積熱歷程）；滑鼠移到時間軸上會預覽該步驟名稱。
- 想一想：每章 4 題，答完標出對錯並計分，可重做。
- 疊構拼圖：把九張介電材料放回 L1–L10 之間，可點選或拖曳，附檢查、三段提示與重新開始；手機上材料區會固定在畫面上方。
- 製程步驟會顯示「廠內常聽到」用語，例如棕化、化學沉銅、電鍍填孔、LDI。
- 動手算一算：殘銅率滑桿可看介電厚度與全板總厚如何變化，並對照 0.75 ± 0.076 mm 公差；微孔深寬比計算器依輸入孔徑與同一組介電厚度，對照 0.8:1 與 1:1。兩者都是簡化模型，不是正式製程資料。
- 1× 預設 7 秒／步，速度可調至 0.5×、1×、1.5×、2×（2× 為 3.5 秒／步）。
- 切換章節會停止播放；切到其他瀏覽器分頁也會暫停。系統啟用減少動態效果時，保留逐步教學，停用連續移動。

## 技術範圍

內容依 `review.md` 與原始疊構圖。孔徑、線路、中央孔工法與實際製程條件沒有被指定為正式生產資料。全厚度孔示例只接 L1／L10，其他層避空；上下微孔堆疊沒有假定穿過中央 Core。工程待確認項與參考來源收在頁面底部。

## 驗證

`tools/verify.cjs` 使用本機已安裝的 Edge 與 Codex 隨附 Playwright 檢查互動。檢查包含所有製程幀的銅層數量與英文解說、上下各四個微孔的介電跨距、入門與工程解說同時顯示、材料／孔型切換、播放控制、四個材料畫面的圖形差異、錯位微孔、知識補充與廠內用語、原圖對照、自選路徑、製程計數器與時間軸預覽、測驗與拼圖、殘銅率與深寬比計算、壓合／固化視覺區別、320–1440px 排版、材料 SVG 文字邊界、減少動態效果與 `file://` 離線運行。結果記錄於 `verification.json`。材料預覽為 `preview-material-0.png` 到 `preview-material-3.png` 及 `preview-material-mobile.png`。

`tools/preview.cjs` 是選用的本機預覽服務，僅對 127.0.0.1 提供此頁與修訂稿；直接開啟 HTML 不需要此服務。
