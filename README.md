# PCB 裡面發生什麼事？10 層 Any-layer HDI 互動教學

用一張 10L any-layer HDI 疊構圖，一層一層看懂 PCB 的結構、PP／Core 材料、四次 build-up 製程、孔連接，以及細線路的 mSAP／SAP／RDL 工法。介面與解說採繁體中文／英文並列。

- **線上版**：https://pcb-hdi-stackup.vercel.app/
- **版本**：v1.5.1（2026-10-30）
- **離線使用**：用 Edge 或 Chrome 直接開啟 `index.html`。不需要安裝套件、登入帳號或付費 API，原始疊構圖已內嵌在網頁裡。

## 教學章節

| 章節 | 內容 | 互動 |
|---|---|---|
| 01 結構探索 | 10 個銅層、8 個 PP 介電層、中央 Core、兩面防焊 | 點選任一層看厚度與用途；展開剖面；切換「薄層放大」或「依 mil 比例」；原圖同步以綠框標出對應列，也能直接點原圖選層 |
| 02 材料介紹 | PP 成分、壓合填隙、固化結合、Core 與 PP 對照 | 四個畫面逐步播放；壓合時有壓板與樹脂流動箭頭，固化後壓板移開 |
| 03 製程播放 | 中央 Core → 四次對稱積層（每次 8 步）→ 後段加工，共 38 步 | 播放／暫停／逐步／拖曳時間軸；跳到任一次積層；計數器顯示銅層數、壓合次數、已填孔微孔層與熱歷程；滑鼠移到時間軸上可預覽步驟名稱 |
| 04 孔連接 | 微盲孔、堆疊微孔、錯位微孔、全厚度通孔 | 藍色虛線顯示導通路徑；「自選路徑」可任選起訖層，顯示要幾段相鄰層連接、是否經過中央孔 |
| 05 線路工法 | mSAP、SAP、aSAP（先進封裝 RDL）做一層線路的 6 步：壓膜、開孔、清孔、打底、長線路、去底 | 單一工法逐步播放，或三欄並排比較同一步；演進軸從 Tenting、Pattern Plating 連到軟硬結合板課程；「去底會啃掉多少線」滑桿 |

## 線路工法（第 05 章）

三種細線路工法：**mSAP**（modified Semi-Additive Process，改良型半加成法）、**SAP**（Semi-Additive Process，半加成法）、**aSAP**（advanced Semi-Additive Process，先進半加成法，用來做先進封裝的 **RDL**，Redistribution Layer，重布線層）。三者的步驟名稱一樣，差在電鍍前那層「底」：mSAP 是超薄銅箔加化學銅（2.5–5 µm），SAP 是咬粗表面上的化學銅（1–2 µm），aSAP／RDL 是電漿清孔後濺鍍的鈦＋銅（50–500 nm）。底越薄，去底時蝕得越少，線就能越細。
- 剖面依社群圖文〈電路板系列番外｜一層線路怎麼做〉的架構重畫成 SVG，沒有嵌入原圖。
- 數值依 Fraunhofer IZM（IMAPS 2024）與 MacDermid（PCD&F 2018）原文查證；ULVAC、JIEP、日月光為原貼文引述。
- 製程章的「填孔鍍銅」「形成線路」兩步有按鈕連到本章，說明 mSAP 是用同一次圖形電鍍完成填孔和長線。
- 同樣內容也放在軟硬結合板課程網站的 `fine-line.html`（兩邊共用同一份繪圖核心）。
- 網頁上的工法標題、演進軸、三欄並排都寫出英文全名，章末附縮寫對照表：

| 縮寫 | 英文全名 | 中文 |
|---|---|---|
| mSAP | modified Semi-Additive Process | 改良型半加成法 |
| SAP | Semi-Additive Process | 半加成法 |
| aSAP | advanced Semi-Additive Process | 先進半加成法（Fraunhofer IZM 用語） |
| RDL | Redistribution Layer | 重布線層：晶片與載板之間的細線路 |
| ABF | Ajinomoto Build-up Film | 味之素增層膜 |
| PID | Photo-Imageable Dielectric | 感光型絕緣層 |
| PVD | Physical Vapor Deposition | 物理氣相沉積（濺鍍屬於此類） |
| LDI | Laser Direct Imaging | 雷射直接成像 |
| L/S | Line / Space | 線寬／線距 |


## 練習與計算工具

- **想一想**：每章 4 題（共 5 章），答完標出對錯並計分，可重做。
- **疊構拼圖**：把 9 張介電材料（1037MR、1067MR、1037HR、Core）放回 L1–L10 之間。可點選或拖曳，附檢查答案、三段提示與重新開始。
- **殘銅率滑桿**：拖動內層殘銅率（10–100%），看介電厚度與全板總厚如何變化，並對照 0.75 ± 0.076 mm 公差。70% 時與圖面總厚 0.772 mm 一致。
- **去底滑桿**（第 05 章）：選工法帶入底厚或自己拖動，設定光阻開口，看去底後線剩多寬。簡化成等向蝕刻。
- **微孔深寬比計算器**：輸入雷射孔徑，以滑桿算出的介電厚度計算各層深寬比，對照 0.8:1 建議值與 IPC-2226 的 1:1 上限。

這些計算器都是簡化模型，只用來說明趨勢，不是正式製程資料。

## 內容範圍與限制

- 層別、厚度、材料註記與 Notes 依原始疊構圖。製程動畫是一般原理示意，不是製造作業指導書。
- 圖面沒有提供孔徑、線路、中央孔工法、壓合曲線與驗收規格。頁面上把這些標為「待確認」，不自行假設數值。
- 全厚度孔示例只接 L1／L10，其他層避空；上下兩半的堆疊微孔不假定穿過中央 Core。
- 外部資料（EMC EM-370(Z)-15 資料表、IPC-4412 布種、IPC-2226 深寬比）只作為參考，不代表本板實際供料或驗收標準。完整來源見 `review.md` 第 8 節與頁面底部。
